# Setup

- Prerequisites: `gh` and `git` available in the user's `PATH`.

Guide the user through configuring a Fine Grained Personal Access token (PAT)
for Github.

- [Setup Link - Github Web](https://github.com/settings/personal-access-tokens)
  with the repository access and permissions the agent should have.
- [Documentation](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens#creating-a-fine-grained-personal-access-token)
- Recommend the following defaults.
  - Set expiry to 30 days.
  - Set RO access to only this repository contents.
